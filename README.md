# My Projects

A collection of my software development projects, built to apply my knowledge, explore new technologies, and improve my development skills.

## 🚀 Projects

### 1. Amazon Homepage Clone

A frontend clone of the Amazon homepage, recreating its layout and visual design using HTML and CSS.

**Technologies:** HTML, CSS

**Features:**
- Navigation bar with search section
- Product category sections
- Hero section and footer
- Styling inspired by Amazon's homepage

### 2. Tic-Tac-Toe Game

A classic two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Interactive 3 × 3 game board
- Win and draw detection
- Reset game and new game options
- Dynamic game status messages

### 3. Stone Paper Scissors Game

An interactive game where you compete against the computer.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Interactive stone, paper, and scissors choices
- Computer-generated moves
- Score tracking for the player and computer
- Messages indicating wins, losses, and draws

### 4. Currency Converter

A web-based currency converter that allows users to convert an amount from one currency to another using exchange-rate data from an external API.

**Technologies:** HTML, CSS, JavaScript, CurrencyAPI

**Features:**
- Currency selection using dropdown menus
- Exchange-rate retrieval through an API
- Dynamic conversion based on the entered amount
- Currency flag icons
- Asynchronous API requests using `async/await`

## 🛠️ Technologies Used

- **HTML5** — Webpage structure
- **CSS3** — Styling and layouts
- **JavaScript** — Game logic, interactivity, and API integration
- **REST APIs** — Fetching exchange-rate data
- **Git & GitHub** — Version control and project management
